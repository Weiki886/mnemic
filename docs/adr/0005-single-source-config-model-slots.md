# ADR-005：配置单源与模型三槽位

状态：已接受（2026-09-16，#1 §11 工程决策冻结）

## 上下文

多客户端（CLI/Web/插件/MCP）若各自持有模型配置，Key 分散且不可审计；模型用途不同（对话/提取/embedding）对稳定性与成本的要求也不同。

## 决策

- **配置单源**：存服务端加密库，Web/CLI 共享一套配置 API；Key 不回传前端、不入日志。
- **三槽位**：chat / 提取 / embedding 独立指派；embedding 为部署级配置，更换走 REEMBED 流程。
- **双协议适配层**：OpenAI 兼容协议为底座 + Anthropic Messages 协议；新模型经"协议 + base_url + Key + 模型名"接入，纯 API 不做本地部署。

## 理由与取舍

单源配置消除多端漂移；槽位化使实验可锁定参考模型（#1 §11），embedding 更换的高成本显式化。代价是首次接入需写配置 API——已在 #14 范围。

## 后果

- 领域模块禁止直接 import 模型 SDK，只能经 infra/llm 适配层（#42 §4）。
- 实验报告引用模型名称/版本/温度快照（model_snapshot）。
