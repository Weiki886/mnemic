# 用量客户端（#36，拆分 3/3）

基于 [模型记录](model-usage.md) 和 [查询/导出 API](usage-reports.md)，本轮补齐 CLI 与 Web 展示。
三个 PR 合入后才关闭 #36。没有增加模型调用、单价写入接口、依赖或迁移。

## CLI

通过现有 `pnpm cli chat --project <项目UUID>` 进入交互后使用：

```text
/usage
/usage --current
/usage --from 2026-10-01T00:00:00Z --to 2026-10-02T00:00:00Z --group-by model
```

默认查询全项目近30天；`--current` 只查询当前物理会话，不累计续聊引用的旧会话。
时间为带时区 ISO，from 包含/to 不包含；服务端最多接受366天。分组可用 day（UTC）、model、purpose、conversation。
只有命令名称支持 Tab 补全。重复参数、未知参数、非法日期在本地拒绝；没有会话时 `--current` 不请求服务端。

输出包含实际 UTC 窗口、调用成功/失败/中断数、累计耗时、五种 token 的已报告量和未报告次数。
token 与费用保留十进制字符串，不经 JavaScript Number 或金额舍入。
CLI 最多展示20个分组，服务端分组或客户端显示被截断时明确提示；总计仍覆盖完整选择范围。
输出中的远端文本通过既有终端控制符过滤；失败只给固定提示，不重试或将命令当作聊天发送。
命令复用 Ink 的忙碌/退出等待机制，生成期间不会并发操作；`/usage` 本身不提交会话、不触发提取。
正常退出仍按原有 `/exit` 规则提交，后台写回可能计费。

## Web

项目连接表单验证项目 UUID 与 Bearer Token 后，导航到「用量」。Token 仍只存在内存，不放进 URL 或 Storage。
表单提供开始/结束 ISO 时间、可选物理会话 UUID 和分组方式；空时间采用服务端默认窗口。
按「查询 / 刷新」读取。没有后台定时请求；模型和后台写回尚未结束时，统计可能需要稍后刷新。

页面展示实际 UTC 窗口、状态计数、耗时、五种 token 的缺失覆盖率、已知部分估价和未估价调用数，
以及价格配置指纹与分组明细。无数据、错误、加载和分组截断均明确显示。
查询新项目/切换 API/再次提交后，旧请求结果与错误不会覆盖新请求；卸载时结果失效。
UUID/时间格式无效不发请求；服务端负责366天范围、项目/会话配对和鉴权，错误不显示原始异常。

## 读数与验收

`reported` 是已知部分，必须结合 missing_calls 读取；embedding 的输出量可不适用。
reasoning 与 cached-input 是 provider 明细，不额外叠加为新收费 token，provider total 不重算。
缺少价格或必要 token 时显示「费用未知」；有部分估价仍列明未估价次数，不能把部分金额称完整账单。
价格由服务端配置，不自动查询或假设供应商定价；本轮没有用真实付费模型核对账单。
CSV/JSON 导出沿用2/3的有界 API，不额外承诺 Web 下载按钮或 shell `mnemic usage` 命令。

| #36 目标/验收              | 证据                                                                       |
| -------------------------- | -------------------------------------------------------------------------- |
| chat/提取/embedding 均记录 | 1/3 SDK/真实PG与HTTP测试，错误/中断/重试计数                               |
| 项目/会话/时间查询         | 2/3作用域负面、窗口与精度测试；本轮 CLI --current 与 Web 筛选/项目切换测试 |
| CSV/JSON 导出可用于评测    | 2/3 CSV/微秒游标测试；真实8条调用→92输入/16输出/124总量→分页8条，数值一致  |
| CLI 展示                   | /usage 解析/读取单测和真实 Ink Tab/当前会话测试，无聊天/提交调用           |
| Web 面板                   | 页面状态/缺失覆盖/精度/并发测试，项目 gate→用量导航→Bearer 请求测试        |

上述测试只使用离线 SDK/临时项目与隔离测试库。记录、估价不是服务商账单或停止计费的证明；
DB/进程故障缺行、跨页非长期 snapshot 等边界沿用前两轮。回滚只移除客户端入口，调用历史不变。
