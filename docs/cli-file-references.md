# CLI 文件引用（#35，拆分 3/3）

本轮把 [本地读取组件](file-context.md) 与 [服务端 Evidence](file-evidence.md) 接入实际 CLI，
沿用既有 Ink 行编辑和 SSE，不新增依赖、表或迁移。此前两轮文档描述的是各自的历史交付范围。
本轮 PR 仅在 owner 审查合入后关闭 #35。

## 行为与取舍

显式 `@` 引用表示用户要求读取并随这条消息发送，**不再增加读取确认弹窗**；#34 三模式均允许普通文件读取。
只解析用户提交的输入，不解析模型输出或把文件内容当作命令。root 取 CLI 已验证的 `--root`，
缺省为启动目录；不因为模型、HTTP 或会话切换而扩大本地根目录。
备选是把正文直接拼进用户文本、静默跳过错误附件或失败后走旧接口。本轮复用独立附件契约，
在任何消息/会话请求前完成读取与字节预算校验；错误保留原稿，不重发、不降级为普通文本。

```text
解释 @src/index.ts
比较 @"src/a b.ts" @README.md
概览 @docs/
```

- Tab 只在光标处的 `@path` 执行有界元数据补全；单候选补全，多候选仅展示，不自动发送。
  空格路径自动加双引号；引用后已有文字保留；目录引号内保留光标，便于继续输入文件名。
- 支持未闭合引号前缀的补全，但未闭合引号不能提交。路径中的双引号没有转义语法，
  含双引号名称不参与补全。邮箱、`@@` 与斜杠命令参数不触发路径枚举。
- 异步结果绑定输入对象和请求序号：输入/光标变化、新 Tab、开始发送、关闭或卸载都会使旧结果失效。
  不用过时目录结果覆盖用户正在编辑的内容。
- 无引用的普通消息不读取本地目录；单独使用 ChatSession 的嵌入方必须显式提供根目录才能加载引用，
  不会默默使用进程 cwd。

## 准备、提示与取消

发送前只读取一次，以该次快照构造共享契约。显式文件失败使整条消息失败。
目录自动选择关键文件时可能因二进制、链接或预算跳过，CLI 在发送前显示路径和原因；
截断也明确显示。提示只含相对路径/数量/状态，不包含正文。
目录清单正文与文件正文共同经过传输契约的 64 KiB 总预算、16 KiB 单附件预算；
若不满足则保留输入并提示减少引用，不悄悄少传目录清单。

准备读取时 ESC / Ctrl+C 立即阻断后续发送并保留原稿；已发起的只读文件系统调用可能仍在本机收尾。
若文件已准备好但创建会话尚未完成，取消仍不发送消息；已经发起的创建请求可能留下一个空会话。
普通消息既有的“收到 start 后请求取消并等待保存回执”语义不变。
消息已发出时，断线/超时不会自动重试、续传或回退成 JSON；沿用 #33 的保存确认与 `/resume` 核对机制。

生成中展示增量回答；文件随当轮输入提供时，“未召回跨会话记忆”会同时说明已提供项目文件上下文，
避免一边使用文件回答、一边提示“不记得”。续聊历史中的附件明确标为项目文件并保留截断标记。

## 数据与安全边界

普通文件、目录清单及选出的关键文件作为附件发往配置的服务端；服务端再提供给 chat/extraction 模型。
附件使用 #92 的独立已脱敏 Evidence、静态 PROJECT_FILE 权威及父引用，不复制到派生 trace 或改成用户修正。
对话输入文字仍是用户自己提交的消息；不要把凭据写进输入或文件名。
Secret 扫描仅覆盖已知模式，不是完整秘密/PII 检测；数据块编码不是 Prompt Injection 防护保证。
文件不能指挥 CLI 执行代码或修改文件，本轮不增加 Tools 执行器或 shell。

保留 #91 的链接/越界/常见敏感路径拒绝、UTF-8 与特殊文件保护、枚举上限和非 OS sandbox 边界。
本轮仅验证 macOS 与 Linux/CI，不声明 Windows 支持。真实终端测试需要 python3 标准库 PTY；运行时不依赖 Python。
测试只用临时项目、隔离 PG 与注入模型，不读取用户项目、真实 .env 或授权记录，不调用付费模型。

| -------------------------- | -------------------------------------------------------------------------------------------------------- |
| 单文件/目录、清单+关键文件 | 本地真实 FS 测试；真实 PTY 同时提交空格文件、README 与目录                                               |
| prompt 明确边界            | 共享边界伪造回归、HTTP/PG 模型输入断言、PTY 实际发送                                                     |
| 来源权威随 Evidence        | #92 真实 PG 的 PROJECT_FILE/TOOL_OBSERVATION 重算；本轮 PTY FILE 仍为 50/0.9，有独立父消息与 Evidence ID |
| 大文件截断与提示           | UTF-8 边界/预算测试，Ink 和 PTY 确认提示先于回答、落库 truncated=true                                    |

真实 PTY 同时验证：缺失文件不产生消息、失败原稿保留可编辑、Tab 不发送、Bearer HTTP、
已知 Secret 不入存储/模型/终端、commit 后 Evidence/提取/佐证计数不重复。
取消、异步补全过期和无根目录的本地拒绝另用确定性会话/Ink 测试覆盖。
本轮不验证真实模型对文件中恶意指令的遵从程度，也不宣称工具生产者已上线。
